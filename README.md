AAC For All – Free AAC Tablet & App Resource

A non-profit project providing low-cost Android AAC tablets and free, open-source communication apps for non-speaking and autistic children.
This website aims to make Augmentative and Alternative Communication (AAC) more accessible for families who need it most.
